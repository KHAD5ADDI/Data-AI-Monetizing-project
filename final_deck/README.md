# Verbatim: final pitch deck

- `Verbatim_Pitch_Deck.pdf`: the cover, the 10 required slides and the closing page.
- `verbatim-pitch.html`: the presentation version, with speaker notes. Open it in a browser, then use the left and right arrows, `F` for full screen and `N` for notes.
- `story.md`: slide content and speaker notes.
- `metrics.py`: the assumptions and calculations behind the figures.
- `scripts/figures.py`, `img/` and `data/`: the charts and the real PoC output shown on the demo slide.

Rebuilding the deck requires the private `datastory` presentation tool, which is not part of this repository.
